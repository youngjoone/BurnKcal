# 추천 레시피의 영양 정보

## 두 가지 출처

- **AI 추천:** Gemini가 재료량·조리법과 함께 1인분 칼로리·단백질·탄수화물·지방을 추정합니다. 서버와 앱이 숫자·범위·열량 일관성을 검사하지만 실측 영양값이나 공인 식품 DB 조회 결과는 아닙니다.
- **기본 레시피 6종:** `mobile/src/data/nutrients.ts`의 USDA FoodData Central SR Legacy 식품별 100g 데이터를 `recipes.ts`의 재료 중량에 비례해 합산합니다. 앱에 포함한 정적 자료이며 실시간 영양 DB 검색은 아닙니다.

목록과 상세 화면 모두 kcal 및 탄단지(g)를 표시합니다. AI 응답 실패 시 기본 레시피임을 명시하고 같은 제외 조건으로 대체 후보를 고릅니다. 추천을 열어 보기만 해서는 식사로 저장되지 않습니다. 현재 사진·음식 이름 분석으로 저장한 식사에는 탄단지를 저장하지 않습니다.

## 기본 레시피 계산 기준

`각 영양소 합계 = Σ(식품의 100g당 값 × 가식부 중량g / 100)`입니다. 칼로리는 정수, 탄단지는 소수 첫째 자리로 표시합니다. 원자료의 에너지 값을 사용하므로 단순 4·4·9 환산과 정확히 일치하지 않을 수 있습니다.

밥·병아리콩은 조리 후 중량, 닭가슴살은 익힌 중량, 연어는 생것 중량, 달걀은 껍질을 뺀 중량입니다. 참치는 무염 물 통조림의 물기를 뺀 중량입니다. 야채·소스·기름도 각각 포함합니다. 조리 손실, 제품별 배합, 실제 남긴 기름이나 양념은 반영하지 못합니다. 국내 제품·실제 식사와 차이가 있을 수 있습니다.
