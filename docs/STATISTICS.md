# 월별·연도별 식사 통계

하단 **통계**에서 월별/연도별로 전환합니다. 월별 날짜를 누르면 해당 날짜 기록으로, 연도별 월을 누르면 해당 월 통계로 이동합니다.

- `domain/statistics.ts`가 저장된 식사의 `localDate`로 집계합니다. 생성 시각이 다른 과거 기록도 선택한 식사 날짜에 포함합니다.
- 삭제한 기록·미래 날짜는 제외합니다. 복구·수정 시 유효한 음식 목록에서 다시 계산합니다.
- **기록일 평균 = 총 기록 칼로리 / 식사를 기록한 날짜 수**입니다. 연평균도 이 방식이며 월평균의 단순 평균이 아닙니다.
- 미기록일은 평균에서 제외합니다. 0 kcal 식사를 저장한 날과 미기록일을 구분합니다. 기록이 없으면 평균은 `null`이며 화면에 값 없음으로 표시합니다.
- 기록한 날의 분모는 선택 기간 중 오늘까지의 날짜 수입니다. 한 끼만 기록해도 기록일에 포함되므로 평균을 실제 하루 섭취량으로 해석할 수 없습니다.
- 월 그래프는 날짜별 총합, 연 그래프는 월별 기록일 평균입니다. 표에 정확한 값과 기록 수를 함께 표시합니다.
- 기기 현지 날짜·윤년·월말·연도 경계를 처리하고 미래 기간 이동을 막습니다. DB 읽기 실패를 0 kcal로 표시하지 않습니다.

현재 통계는 칼로리와 기록 횟수입니다. 과거 목표 변경 이력, 체중 추세, 저장한 식사의 탄단지 통계는 포함하지 않습니다.
