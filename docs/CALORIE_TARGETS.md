# 하루 목표 계산

신체 정보는 기기에만 저장하며 AI 서버로 전송하지 않습니다. 자동 목표는 추정 시작점이며 의료 처방·절대적인 섭취 상한이 아닙니다.

## 계산과 제품 정책

1. Mifflin–St Jeor 휴식 대사량 추정: `10 × kg + 6.25 × cm - 5 × 나이 + 성별 계수` (남성 5, 여성 -161).
2. 활동량 배수 1.2 / 1.4 / 1.6을 적용합니다. 활동량 구분과 배수는 초기 제품 가정이며 개인 측정값이 아닙니다.
3. 목표가 현재보다 0.5kg 이상 낮으면 -300 kcal, 높으면 +200 kcal, 비슷하면 유지값입니다. 목표 체중 차이에 비례해 감량을 급격하게 키우지 않습니다.
4. 50 kcal 단위 반올림, 자동 목표 하한 1,500 kcal. 이 하한은 보수적인 앱 정책이며 모든 사람에게 충분하다는 뜻이 아닙니다.
5. 18세 미만·80세 초과, 임신/수유/의료적 식사 관리, 현재 또는 목표 BMI 18.5 미만, 계산값 4,000 kcal 초과에는 자동 목표를 제안하지 않습니다. 기록 기능은 사용 가능합니다.
6. 목표 달성 기한과 체중 변화 예측은 구현하지 않습니다. 전문가 검토·개인 변화에 따른 재평가가 필요합니다.

남은 칼로리는 목표에서 오늘 확정 기록을 뺀 값입니다. 화면은 0 이하를 0으로 표시하고 초과량을 별도로 알립니다. 기록을 수정·삭제하면 합계에서 다시 계산합니다. 굶기나 보상 운동을 권하지 않습니다.

## 근거와 한계

- [Mifflin et al., 1990 원 논문](https://pubmed.ncbi.nlm.nih.gov/2305711/): 휴식 대사량 추정식. 식사 목표 전체 정책이 임상 검증됐다는 뜻은 아닙니다.
- [NIDDK Body Weight Planner](https://www.niddk.nih.gov/health-information/weight-management/body-weight-planner): 성인용 도구와 임신·수유 제외 안내. 이 앱은 NIDDK 동적 모델을 구현한 것이 아닙니다.
- [NIDDK 음식량 안내](https://www.niddk.nih.gov/health-information/weight-management/just-enough-food-portions): 나이·체중·대사·성별·활동량에 따라 요구량이 달라집니다.

자동 계산 대상 확인은 본인 입력에 의존합니다. 이 앱은 질환이나 영양 상태를 판별하지 않습니다.
