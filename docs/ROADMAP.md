## 3. AI 연결 — 계획, 미구현

비용을 고려한 첫 평가 후보는 Gemini 3.1 Flash-Lite입니다. 공급자·모델의 최종 선정과 API 키 설정은 별도 단계입니다.
2026-09-12 기준 표준 유료 요금: 입력 100만 토큰당 $0.25, 출력(추론 포함) $1.50.
사진당 고정 비용이 아니므로 실제 토큰 사용량을 기록해 평가해야 합니다.
[Google 가격표](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite)

- `FoodAnalyzer` 구현 추가, 서버 환경 변수로 키와 모델 지정
- JSON 구조와 숫자·합계 검증, 시간 초과·한도 초과·AI 실패 처리
- 비음식·불명확한 사진 처리, 설명 반영, 실제 분석과 데모 명확히 구분
- 한 사진에서 구분 가능한 음식을 각각 인식해 이름·추정량·칼로리 반환. 중복 집계 없이 항목 합으로 총합 계산
- 가려지거나 구분할 수 없는 음식은 확정하지 않고 불확실성 안내
- 음식과 양을 알고 있는 샘플로 정확도·지연·비용 비교
- 무료/유료 API의 데이터 사용 조건을 확인한 후 실제 사용자 사진 적용
